Privacy Policy

Last updated: 2 November 2026

actstocks_autoupload ("the app") is a personal tool used only by its owner to upload files from a folder on the owner's own computer to the owner's own Google Drive.

Data the app accesses

The app uses the Google Drive API only to upload files into a Google Drive folder chosen by the owner. It does not read, download, modify, or delete any other files in Google Drive.

How data is stored

The Google sign-in token is stored only on the owner's computer. Uploaded files are stored only in the owner's Google Drive. No data is sent to any server other than Google.

Sharing

The app does not collect, share, sell, or transfer any user data to third parties.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
